# ♠ 채스베이거스 (Chae's Vegas)

가족 홀덤 나이트를 위한 **토너먼트 매니저 웹앱**입니다. 블라인드 타이머, 딜러 버튼 관리, 칩 은행 재고, 리바이인/탈락 관리, 최종 정산까지 한 화면에서 처리합니다.

별도의 빌드 과정 없이 `index.html` 파일 하나로 동작합니다.

## 주요 기능

- **플레이어 설정** — 2~8명 선택, 좌석 순서대로 이름 입력 (1번 좌석 = 딜러 시작 · 은행)
- **블라인드 타이머** — 3레벨 × 60분(약 3시간), 인원수별 블라인드 구조 자동 적용
  - 마지막 5초 카운트다운 비프음, 레벨 전환 시 알림음 (Web Audio API)
  - 이전/다음 레벨 이동, 리셋, 일시정지
- **테이블 뷰** — 딜러(BTN) / SB / BB 자동 표시, 헤즈업(2명) 규칙 반영, 탈락자 딜러 버튼 자동 이동
- **칩 은행 관리** — 인원수별 칩 지급량, 은행 잔여 재고, 리바이 가능 횟수 표시
- **리바이인 / 탈락 관리** — 바이인 횟수와 총 팟, 평균 스택(BB 단위) 실시간 계산
- **패 순위표** — 포커 족보 10종을 카드 예시와 함께 항상 표시
- **GTO 프리플랍 차트** — 포지션별(UTG/MP/CO/BTN/SB/BB) 오픈 레인지 13×13 매트릭스 (100BB 6-max 근사치)
- **최종 정산** — 칩 개수 또는 금액 직접 입력, 칩 합계 불일치 경고, 은행 기준 송금 내역 계산, 결과를 이미지(PNG)로 저장/공유
- **자동 저장** — `localStorage`에 진행 상황을 저장하여 새로고침해도 복구 (타이머는 일시정지 상태로 복구)

## 칩 구성

| 칩 | 가치 | 총 보유 수량 |
| --- | --- | --- |
| Black | 100원 | 100개 |
| Green | 500원 | 50개 |
| Red | 1,000원 | 50개 |
| Sky | 5,000원 | 50개 |

- 바이인: **20,000원** (1인 스택 기준)
- 인원수별 1인당 지급 칩 개수는 `index.html`의 `ALLOCATION` 상수에서 설정합니다.

## 블라인드 구조

레벨당 60분, 총 3레벨 (SB/BB).

| 인원 | Lv.1 | Lv.2 | Lv.3 |
| --- | --- | --- | --- |
| 2명 | 200/400 | 500/1,000 | 1,000/2,000 |
| 3~4명 | 100/200 | 300/600 | 600/1,200 |
| 5명 | 100/200 | 300/600 | 800/1,600 |
| 6명 | 100/200 | 400/800 | 1,000/2,000 |
| 7~8명 | 100/200 | 500/1,000 | 1,500/3,000 |

## 사용 방법

1. 저장소를 클론하거나 `index.html`을 내려받습니다.
2. 브라우저(모바일 포함)에서 `index.html`을 엽니다.
3. 인원 수와 이름을 설정하고 **게임 시작**을 누릅니다.
4. 타이머를 시작하고, 핸드가 끝날 때마다 **다음 핸드**로 딜러 버튼을 이동합니다.
5. 게임이 끝나면 **게임 종료 / 정산**에서 각자의 최종 칩을 입력해 정산합니다.

> CDN에서 라이브러리와 폰트를 불러오므로 **인터넷 연결이 필요**합니다.

## 기술 스택

모두 CDN으로 로드하며 별도 설치가 필요 없습니다.

- [React 18](https://react.dev/) (UMD) + [Babel Standalone](https://babeljs.io/docs/babel-standalone) — 브라우저에서 JSX 직접 컴파일
- [Tailwind CSS](https://tailwindcss.com/) (Play CDN) + 커스텀 CSS (펠트/골드 테마)
- [html2canvas](https://html2canvas.hertzen.com/) — 정산 결과 이미지 캡처
- Web Audio API — 타이머 알림음
- Google Fonts (Noto Serif KR), [Pretendard](https://github.com/orioncactus/pretendard)

## 참고

- 정산은 **1번 플레이어가 은행** 역할을 하며, 게임 중 받은 바이인을 기준으로 최종 칩 금액을 다른 플레이어에게 지급하는 방식입니다.
- GTO 프리플랍 차트는 솔버의 정확한 값이 아닌 근사치이며, 스택이 20BB 이하로 줄면 더 타이트하게 플레이하는 것이 좋습니다.
